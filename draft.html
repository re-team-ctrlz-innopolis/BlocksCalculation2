BlocksCalculator guide

Welcome

1. Move around the plan

Use the mouse wheel to zoom in or out. Hold the left mouse button and drag an empty area of the plan to move the view. Use Show course in the legend to switch between the first two horizontal rows of blocks.

2. Add, edit and connect walls

Click Add wall to create a wall. Select any wall to change its length and height in the panel on the right. Use Turn left or Turn right to rotate the selected wall by 90 degrees. To connect perpendicular walls, drag a wall until its end snaps to another wall. L- and T-junctions are created automatically.

3. Add openings

Select a wall and click + Opening. Choose Window or Door, then set its width, distance from the start of the wall, starting course, and height in courses. A course is one horizontal row of blocks. Drag an opening along the wall on the plan. Use the side view below the plan to move a window up or down. Doors start at floor level, in course 1. Windows start at course 2 or above.

4. Check the layout

Block counts update automatically as you edit. The side view shows how the blocks are arranged in each row. Control joints divide long walls into sections no longer than 5 m. Their positions may shift to avoid openings. Fix any errors shown in the panel on the right before printing or exporting the results.

5. Save your work

Choose File → Save project to download an editable JSON project file. Use File → Open project to load it again. Choose Print / Save PDF for a printable report, or Export CSV to download the block quantities for a spreadsheet. Use Undo to reverse an edit and Redo to restore it. Click Guide to open these instructions again.
